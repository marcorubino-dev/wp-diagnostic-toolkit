# Security Policy

## Supported versions

This project is under active development. Security fixes are applied to the current development branch (`main`). No stable release support policy is established yet.

## Reporting a vulnerability

Please do not report suspected vulnerabilities in public issues, discussions, or pull requests.

Use GitHub's private vulnerability reporting feature for this repository when it is available. If that option is unavailable, contact the maintainer through the contact options on the GitHub profile:

https://github.com/marcorubino-dev

Include, where possible:

- A concise description of the issue and its potential impact.
- The affected commit, version, or component.
- Reproduction steps or a minimal proof of concept.
- Any relevant environment details.

Do not include real credentials, customer data, production secrets, or other sensitive information in the report.

## Disclosure

Please allow the maintainer reasonable time to investigate and coordinate a fix before publicly disclosing the vulnerability. No fixed response or resolution time is guaranteed.
